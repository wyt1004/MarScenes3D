# Installation

The conversion and evaluation tools are tested with Ubuntu 20.04,
Python 3.10, NumPy 1.24, and SciPy 1.14. The core tools do not require CUDA.

Create an isolated environment first, then install the project dependencies:

```bash
conda create -n marscenes3d python=3.10 -y
conda activate marscenes3d
python -m pip install --upgrade pip
python -m pip install -r requirements.txt
```

For the optional OpenPCDet model integration, install the matching PyTorch and
CUDA packages from `requirements-openpcdet.txt`, then build operators in the
external model repository. For TrackEval, YOLO, and visualization, install the
corresponding optional requirements file.

The repository intentionally does not ship a standalone `pcdet` package or
model checkpoints. It is an adapter repository: copy the dataset adapter into
the selected OpenPCDet-compatible project, or add this repository to that
project's Python path.

The 3D adapter under `adapters/openpcdet/` follows the OpenPCDet environment
and package layout. The optional YOLOv8l and YOLOv10l baselines are pinned to
Ultralytics 8.4.30 (AGPL-3.0).

The standalone 3D detection viewer uses Open3D and is available through
`requirements-visualization.txt`; it does not require an OpenPCDet model or
checkpoint.

## Registering the 3D adapter

The adapter is deliberately not installed as a second `pcdet` package. Keep
this repository on `PYTHONPATH` while running the external OpenPCDet checkout:

```python
from adapters.openpcdet.marscenes3d_dataset import bind_to_openpcdet
MarScenes3DDataset = bind_to_openpcdet()
```

Add those two lines to the external project's `pcdet/datasets/__init__.py`
(or import the class from an equivalent local registration module), for
example:

```bash
export PYTHONPATH=/path/to/MarScenes3D:/path/to/OpenPCDet:$PYTHONPATH
```

If the external project requires local dataset files, copying the adapter into
`pcdet/datasets/` is also supported, but retain the repository root on
`PYTHONPATH` so its `utils/` package can be imported.

Use `adapters/openpcdet/marscenes3d_dataset.yaml` as the dataset configuration,
adjust `DATA_PATH`, and point `INFO_PATH` at the files generated by
`tools/prepare_openpcdet.py`. The class names in that YAML must match the
dataset labels. Keep model code, CUDA operators, and checkpoints in the
external OpenPCDet-compatible repository.
